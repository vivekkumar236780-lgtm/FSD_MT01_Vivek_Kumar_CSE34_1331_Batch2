
# Product Inventory Management API

## Project Description
A REST API for managing product inventory using Node.js and Express.js.

All product records are stored in an in-memory JavaScript array.

## Technologies Used
- Node.js
- Express.js
- JavaScript
- Thunder Client

## Features
1. Get all products
2. Add a new product
3. Get product by ID
4. Update product details
5. Delete a product
6. Filter products by category

## Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd ProductInventory
```

Install dependencies:

```bash
npm install
```

Start the server:

```bash
npm start
```

Server runs at:

http://localhost:3000

## API Base URL

http://localhost:3000/api/products

## Storage
Products are stored in an in-memory JavaScript array.
Data resets when the server restarts.
